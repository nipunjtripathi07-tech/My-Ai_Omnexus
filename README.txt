# 🤖 Omnexus AI – Smart Voice Assistant

**Omnexus AI** is a Python-based AI voice assistant that searches the web, retrieves information from Wikipedia, summarizes results using Hugging Face's FLAN-T5 model, and speaks responses using text-to-speech.

## ✨ Features

- 🧠 **AI-Powered Summarization:** Uses Google's FLAN-T5-small model.
- 🌐 **Web Search:** Retrieves information using DuckDuckGo.
- 📚 **Wikipedia Integration:** Fetches information from Wikipedia.
- 🔊 **Text-to-Speech:** Converts AI responses into spoken audio using pyttsx3.
- ⏰ **Time Assistance:** Provides the current time.
- 💬 **Interactive Interface:** Accepts text-based user queries.

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- FLAN-T5 Small
- Wikipedia API
- DuckDuckGo Search
- pyttsx3

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Omnexus-AI
   ```

3. Install the required libraries:

   ```bash
   pip install pyttsx3 wikipedia duckduckgo-search transformers torch
   ```

## 🚀 Run the Project

```bash
python main.py
```

Ask Omnexus questions and receive summarized, spoken responses.
